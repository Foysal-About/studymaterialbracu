## কিভাবে পড়বে (How to study)

1. প্রথমে **Overview (02)** আর **EDA (01)** — descriptive answer গুলো মুখস্থ না, বুঝে লেখার practice করো।
2. তারপর math topics: **Anomaly Detection → Perceptron → ZeroR/OneR/CM/DT → Regression**।
3. প্রতিটা note এর শেষে **Practice Problem** আছে — খাতায় নিজে solve করে answer মিলাও।
4. Exam এর আগের দিন শুধু প্রতিটা note এর **Exam Tips / পরীক্ষার টিপস** section দেখো।
